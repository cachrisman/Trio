**What source=retrieved means in plain English**
`event=g7_ble_connect_attempt source=retrieved` means Trio did not connect from a fresh advertisement callback. It asked CoreBluetooth for peripherals the system already considers connected for the G7 data service, got back a `CBPeripheral`, and connected using that object ([G7DirectBLEManager.swift](/Users/charliechrisman/Code/src/cachrisman/diabetes/Trio/Trio%20Watch%20App%20Extension/G7DirectBLEManager.swift:314), [G7DirectBLEManager.swift](/Users/charliechrisman/Code/src/cachrisman/diabetes/Trio/Trio%20Watch%20App%20Extension/G7DirectBLEManager.swift:323), [G7DirectBLEManager.swift](/Users/charliechrisman/Code/src/cachrisman/diabetes/Trio/Trio%20Watch%20App%20Extension/G7DirectBLEManager.swift:1092)).

`source=scan` means Trio first saw the device in `centralManager(_:didDiscover:advertisementData:rssi:)`, then connected from that advertisement path ([G7DirectBLEManager.swift](/Users/charliechrisman/Code/src/cachrisman/diabetes/Trio/Trio%20Watch%20App%20Extension/G7DirectBLEManager.swift:1191)).

Why that is more interesting: retrieval implies CoreBluetooth already had stronger system knowledge of that exact peripheral than “I just saw an FEBC ad.” Evidence-backed minimum meaning is “the OS already had a connected/known peripheral object for that service.” Hypothesis lane meaning is “the OS may also have had an existing link, remembered identity, cached services, or pending/restored connection context.”

A “better starting relationship” in real Apple Watch terms most plausibly means one or more of:
- the watch OS already had a system-connected G7 peripheral object for the Dexcom-owned session
- the central/peripheral identity was continuous across lifecycle events, not a new scan-hit object
- CoreBluetooth already knew service-level identity for that peripheral
- the attach may have been closer to “join an existing link” than “win a fresh radio connect race”

**Why the retrieved success matters**

The docs’ own watch-only review says build 166 had 17 attempts, 1 `didConnect`, and that one was `source=retrieved`; the other 16 still timed out from scan ([watch-direct-ble-cgm-02-implementation-plan.md](/Users/charliechrisman/Code/src/cachrisman/diabetes/Trio-dev/docs/in-progress/watch-direct-ble-cgm/watch-direct-ble-cgm-02-implementation-plan.md:387), [watch-direct-ble-cgm-02-implementation-plan.md](/Users/charliechrisman/Code/src/cachrisman/diabetes/Trio-dev/docs/in-progress/watch-direct-ble-cgm/watch-direct-ble-cgm-02-implementation-plan.md:902), [watch-direct-ble-cgm-05-diable-comparison.md](/Users/charliechrisman/Code/src/cachrisman/diabetes/Trio-dev/docs/in-progress/watch-direct-ble-cgm/watch-direct-ble-cgm-05-diable-comparison.md:136)).
