## Intent

On the Treatments screen, the Reduced Bolus / Super Bolus radio toggles and the External Insulin checkbox should share one row. The operator had this as part of patch 03 (`treatments-fixed-bottom-action`, commit 8aaab9d2d), but patch 03 was dropped in the 0.8.4 sync (53de1011f, TRIO-030), and upstream 56b5882e1 then extracted the controls into `bolusSection`, where External Insulin is again its own row.

Operator decision (2026-10-19, chat): personal patch, not for upstream. Replace the two radios with a segmented control `Reduced | Normal | Super` (Normal = neither factor applied), and put an "External" checkbox (label shortened from "External Insulin") on the same row. A segment only appears when its setting (fattyMeals / sweetMeals) is enabled; the row is always shown so External stays reachable. Bolus calculator semantics are unchanged: the control maps onto the existing `useFattyMealCorrectionFactor` / `useSuperBolus` flags (never both true) and the recommendation is recalculated on change. View-only change in `TreatmentsRootView.swift`; new standalone patch at the end of the stack from branch `feature/treatments-bolus-mode`.

## Review adjudication (2026-10-19)

Cursor review `.worktrees/treatments-bolus-mode/.task-relay/notes/20261019-192104-88589-cursor-review.md` (0 high, 2 medium, 2 low), no code changes made:

- MEDIUM, External on the same row as the bolus adjustment (accidental-toggle risk): this is the operator's requested layout, restoring what patch 03 did.
- MEDIUM, shorter labels and new localization keys ("Reduced", "Super", "External"): the operator chose these in chat; it's a personal patch, not for upstream.
- LOW, both flags true would show `.reduced` while the calculator applies both: the new setter is the only writer of either flag (`grep` 2026-10-19), so this can't happen today.
- LOW, row width may truncate: tracked as operator AC-4 (on-device check).


## Release note

The Treatments screen picks Reduced, Normal or Super bolus with one segmented control, and the External checkbox sits on the same row. That frees up vertical space without changing how each option adjusts the recommendation.
